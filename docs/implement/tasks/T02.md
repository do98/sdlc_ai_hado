## 1. Mục tiêu

Dựng khung giao diện dùng chung để các task FE sau (T10, T11, T14–T16, T18, T19) chỉ việc gắn tính năng: tokens thiết kế, bộ component nền, lớp gọi API có xử lý lỗi chuẩn, router có bảo vệ đăng nhập và bố cục 3 cột.

## 2. Phạm vi

**Làm:** `shared/ui` (Button, Input, Dialog, Toast, Tooltip, Skeleton), tokens, `shared/api`, `app` (router + guard, bố cục 3 cột), cấu hình test.

**Không làm:** màn hình đăng nhập và logic phiên (T04); component nghiệp vụ như `DocumentRow`, `AnswerCard`.

## 3. Các bước thực hiện

| # | Việc | Đầu ra kiểm tra được |
|---|---|---|
| a | Tokens (màu, chữ, khoảng cách, bán kính, bóng) từ SDD UI/UX và prototype HTML, đặt ở `shared/ui/tokens.css` + cấu hình Tailwind | Trang demo dùng 100% giá trị từ tokens; không có màu/khoảng cách hard-code trong component |
| b | Component nền: Button (primary/secondary/danger, loading, disabled), Input (nhãn, lỗi, bộ đếm), Dialog (bẫy focus, Esc, trả focus), Toast (vùng `aria-live`), Tooltip, Skeleton — dựng trên Reka UI | Mỗi component có test Vitest cho trạng thái + test bàn phím |
| c | `shared/api`: client duy nhất gọi mạng; gửi cookie phiên (`credentials: 'include'`); chuẩn hóa lỗi thành `ApiError{status, code, message, retryable}`; 401 → phát sự kiện "phiên hết hạn"; 403 → thông điệp quyền | Test với MSW: 401/403/5xx/mất mạng ánh xạ đúng |
| d | Bảng ánh xạ mã lỗi → thông điệp tiếng Việt (`shared/api/errors.ts`) với khóa theo mã; mã lạ → thông điệp chung | Test: mọi mã trong T05 có thông điệp; mã lạ không làm vỡ UI |
| e | `app`: Vue Router, guard đăng nhập (chưa đăng nhập → `/login`, nhớ đường dẫn đích), bố cục 3 cột (danh sách tài liệu · hội thoại · bảng nguồn) responsive; ở độ rộng hẹp: cột nguồn thành ngăn trượt | Ảnh chụp ở 3 độ rộng (≥ 1280, 1024, 768) khớp prototype |
| f | Cấu hình Pinia, TanStack Query (vue-query) với khóa truy vấn thống nhất; `ErrorBoundary` cấp ứng dụng | Lỗi render không làm trắng trang |
| g | Chuỗi hiển thị tập trung (`shared/lib/i18n` hoặc tệp hằng số tiếng Việt) | Không còn chuỗi người dùng nằm trong template |

## 4. Đặc tả kỹ thuật

- Ngăn xếp: Vue 3 + TypeScript + Vite, Pinia, Vue Router, `@tanstack/vue-query`, Reka UI + Tailwind (kế hoạch §3).
- Hợp đồng lỗi phía FE: `type ApiError = { status: number; code: string; message: string; retryable: boolean; traceId?: string }`.
- Guard: lưu đường dẫn đích ở bộ nhớ ứng dụng (không dùng `localStorage`); sau đăng nhập quay lại đường dẫn đó.
- Trợ năng: mọi nút biểu tượng có `aria-label`; tương phản ≥ 4.5:1 (đo bằng axe ở T22).

## 5. Tiêu chí hoàn thành

- [ ] Trang demo hiển thị đủ 6 component và 3 trạng thái (bình thường, loading, lỗi) khớp prototype.
- [ ] Mọi lỗi mạng đi qua một chỗ duy nhất (`shared/api`), kiểm chứng bằng luật lint của T01.
- [ ] Router chặn truy cập khi chưa đăng nhập (dùng phiên giả của MSW).

## 6. Kiểm thử

Vitest + Vue Test Utils (component, `shared/api`), MSW (API giả), chụp ảnh thị giác hoặc kiểm tra bằng tay ở 3 độ rộng.
