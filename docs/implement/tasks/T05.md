## 1. Mục tiêu

Chốt hợp đồng IF-02, IF-03, IF-05, IF-06, IF-07 ngay ở GĐ 0 để FE làm trên API giả (MSW) trong khi BE chưa xong, và BE dùng chính hợp đồng làm bộ test.

## 2. Phạm vi

**Làm:** tệp OpenAPI cho REST, tài liệu hóa sự kiện SSE (OpenAPI không mô tả được SSE tốt nên có thêm tệp mô tả sự kiện), bộ MSW mô phỏng đủ kịch bản, kiểm thử hợp đồng.

**Không làm:** hiện thực thật phía BE (T07–T09, T12–T13, T17).

## 4. Đặc tả kỹ thuật

Các hình dạng dưới đây là **đề xuất** `[Đề xuất]`; kế hoạch chỉ cố định tên sự kiện SSE và các ràng buộc ở §3–§5.

**IF-02 `GET /api/documents`** → `200 { items: [ { id, name, sizeBytes, pageCount|null, status, errorCode|null, warning|null, uploadedBy, uploadedAt } ], count, limit: 20 }`. `status ∈ PROCESSING | READY | ERROR`.

**IF-03 `POST /api/documents`** (`multipart/form-data`, trường `file`; **một tệp mỗi yêu cầu** để có tiến trình và thử lại từng tệp) → `202 { id, status: "PROCESSING" }`. Lỗi đồng bộ: `415 NOT_PDF`, `413 FILE_TOO_LARGE`, `409 WORKSPACE_FULL`, `401`.

**IF-06 `GET /api/events`** (SSE, cần cookie phiên): mỗi sự kiện có `id:` tăng dần; `event: document.updated`, `data: { id, status, errorCode, warning, pageCount }`. Hỗ trợ `Last-Event-ID` để phát lại sự kiện đã lỡ; heartbeat `: ping` mỗi 15 giây `[Đề xuất]`.

**IF-05 `POST /api/conversations/{id}/messages`** `{ text }` (≤ 2000 ký tự) → SSE:

| Sự kiện | Dữ liệu | Quy tắc |
|---|---|---|
| `meta` | `{ messageId, conversationId }` | đầu tiên, đúng một lần |
| `status` | `{ phase: "retrieving" \| "generating" }` | có thể nhiều lần |
| `delta` | `{ text }` | nối theo thứ tự |
| `citation` | `{ index, documentId, documentName, page, charStart, charEnd }` | trước `done`; `index` là số `[n]` |
| `done` | `{ result: "answered" \| "not_found" \| "partial", usage }` | cuối cùng khi thành công |
| `error` | `{ code, retryable }` | cuối cùng khi lỗi; không có `done` sau `error` |

**IF-07 `GET /api/documents/{id}/file`**: trả PDF gốc, hỗ trợ `Range: bytes=…` (206), yêu cầu quyền xem; `Content-Disposition: inline`; `X-Content-Type-Options: nosniff`.

Mã lỗi dùng chung: `UNAUTHENTICATED`, `INVALID_CREDENTIALS`, `ACCOUNT_LOCKED`, `NOT_PDF`, `FILE_TOO_LARGE`, `WORKSPACE_FULL`, `EMPTY_QUESTION`, `QUESTION_TOO_LONG`, `NO_READY_DOCUMENTS`, `RATE_LIMITED`, `LLM_UNAVAILABLE`, `TIMEOUT`, `NOT_FOUND`, `INTERNAL`.
